# Screenshots Guide

Add product screenshots to this folder to visually support the technical case study.

## Recommended Screenshots
Include images that demonstrate core marketplace workflows and role-based experiences:

1. Homepage
2. Provider dashboard
3. Customer booking flow
4. Admin dashboard
5. Provider profile page
6. Marketplace listings/discovery view

## Suggested File Naming
Use clear, stable file names so links in documentation remain readable, for example:

- `homepage.png`
- `provider-dashboard.png`
- `customer-booking-flow.png`
- `admin-dashboard.png`
- `provider-profile.png`
- `marketplace-listings.png`

## Suggested Capture Guidelines
- Use realistic but non-sensitive sample data
- Avoid exposing private personal or financial information
- Keep browser chrome and viewport consistent across captures
- Prefer full-page or clearly cropped screenshots that emphasize workflow context

## Optional Next Step
